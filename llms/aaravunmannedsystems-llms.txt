# Aarav Unmanned Systems (Aereo)

> Aarav Unmanned Systems (AUS), rebranded as Aereo in 2023, is an Indian end-to-end enterprise drone
> company founded in 2013 out of IIT Kanpur and headquartered in Bengaluru. It manufactures
> survey-grade UAVs and operates Aereo Cloud, a geospatial platform that turns drone imagery into
> orthomosaics, terrain models, 3D tilesets and AI analytics for mining volumetrics, infrastructure
> monitoring, land records, agriculture and forest conservation.

## What is actually callable

Aereo publishes one machine-readable API contract: the Aereo Cloud **Tile Server**, an OpenAPI 3.1.0
document served at the API host root. It describes twelve read-only operations that deliver map
layers to the Aereo Cloud console. There is no developer portal, no API reference, no SDK, no CLI and
no MCP server.

Important for agents: the published spec declares **no servers[] block and no securitySchemes**, yet
eleven of its twelve operations return HTTP 401 without an `Authorization: Bearer <token>` header.
Only `GET /ping` is reachable anonymously. Token issuance is not publicly documented — it is a
tenant credential for Aereo Cloud customers. Treat this API as effectively customer-only.

## APIs

- [Aereo Cloud Tile Server](https://cloud.aereo.io/): Vector, raster, terrain and 3D Tiles delivery for drone survey data. Base URL https://tiles.aereo.io

## Operations

- `GET /ping` — health check, no credential required
- `GET /vector/{z}/{x}/{y}.pbf` — Mapbox Vector Tile
- `GET /ortho/{z}/{x}/{y}.png` — orthomosaic raster tile from a Cloud Optimized GeoTIFF
- `GET /histogram/{z}/{x}/{y}.png` — histogram-stretched raster tile
- `GET /mbtiles/{z}/{x}/{y}.png` — raster tile from an MBTiles archive
- `GET /terrain/layer.json` — terrain tileset metadata
- `GET /terrain/{z}/{x}/{y}.terrain` — quantized-mesh terrain tile
- `GET /cesium-terrain/layer.json` — Cesium terrain layer.json for a COG
- `GET /cesium-terrain/{z}/{x}/{y}.terrain` — Cesium terrain tile
- `GET /3dtiles/{filename}.{extension}` — Cesium 3D Tiles asset
- `GET /cv-tiles/{filename}.{extension}` — computer-vision derived tileset asset
- `GET /altitude` — point elevation lookup
